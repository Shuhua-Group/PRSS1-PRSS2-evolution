# Duplication of trypsinogen gene (PRSS1-PRSS2) evolution and human pancreatic diseases

This is an overview of data and code for bioinformatics analysis of the study entitled "**Ancient trypsinogen duplications shape pancreatic disease risk through pseudogene enhancers**".

The data and code are stored in the following six sections:

- [01-Primate_Evolutionary_History](./01-Primate_Evolutionary_History/01-Primate_Evolution_History-README.md)
- [02-Human_Population_Haplotype](./02-Human_Population_Haplotype/02-Human_Population_Haplotype-README.md)
- [03-Natural_Selection_Human](./03-Natural_Selection_Human/03-Natural_Selection_Human-README.md)
- [04-Coordinated_Digestive_Enzymes](./04-Coordinated_Digestive_Enzymes/04-Coordinated_Digestive_Enzymes-README.md)
- [05-Expression_Epigenetic_Analysis](./05-Expression_Epigenetic_Analysis/05-Expression_Epigenetic_Analysis-README.md)
- [06-Pancreatic_Disease_Association](./06-Pancreatic_Disease_Association/06-Pancreatic_Disease_Association-README.md)

All the public raw data and algorithm/software used in this study can be found in Methods and Supplementary Tables. GTEx genetic data are available through dbGaP ([text](https://dbgap.ncbi.nlm.nih.gov/home/)) under controlled access.
