# Duplication of trypsinogen gene (PRSS1-PRSS2) evolution and human pancreatic diseases

This is an overview of data and code for bioinformatics analysis of the study entitled "**Ancient trypsinogen duplications shape pancreatic disease risk through pseudogene enhancers**".

The data and code are stored in the following six sections:

01-Primate_Evolutionary_History
02-Human_Population_Haplotype
03-Natural_Selection_Human
04-Coordinated_Digestive_Enzymes
05-Expression_Epigenetic_Analysis
06-Pancreatic_Disease_Association

All the public raw data and algorithm/software used in this study can be found in Methods and Supplementary Tables. GTEx genetic data are available through dbGaP ([text](https://dbgap.ncbi.nlm.nih.gov/home/)) under controlled access.
