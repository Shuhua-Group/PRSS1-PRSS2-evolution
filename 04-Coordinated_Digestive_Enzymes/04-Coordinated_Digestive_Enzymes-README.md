## 4.2 Lipid gene structure and polymorphism

This module applies the same duplication analysis to the lipid genes that share the architecture of  
PRSS1–PRSS2: CEL and CLPS are extracted from the HPRC haplotype-resolved assemblies and their  
duplications are dated with BEAST.

### 4.2.1 Structural inference (Fig. 4C)

Infer the structure of the lipid-gene region in the HPRC assemblies.

```bash
cd data
nucmer <HPRC assembly> b38_CLPS.fasta
```

Raw data: `BEAST.region.txt` — the extraction commands and coordinates of the CEL region in every  
HPRC and Great Ape assembly, grouped by structure (REF, DUP1, DUP2).

Final results: `lipid.gene.haplotype.in.HPRC.anno.v3.xlsx`, `Fig-4.pdf` — the annotated lipid-gene  
haplotype structures observed in HPRC and the figure.

**Software:** Mummer 3.23 (`nucmer`), SAMtools 1.6.

### 4.2.2 CLPS phylogenetic tree (Extended Data Fig. 7C)

Extract CEL and CLPS from the HPRC and Great Ape assemblies and date their duplications.

```bash
cd data
bash ../code/pickCEL.sh
bash ../code/pickCLPS.sh
bash ../code/BEASTtree__fasta_merger.sh -i <dir-with-per-sample-fasta> -n CEL
mafft --auto CEL.fa > CEL_mafft.fa
beast CEL.xml
treeannotator -burnin 10 CEL.mcmc.trees CEL.consensus.trees
```

The BEAUti/BEAST configuration of both runs is:

```
substitution model : HKY (kappa ~ LogNormal(M = 1.0, S = 1.25)), GammaSiteModel
                     (gammaCategoryCount = 5)
clock model        : strict clock, clockRate.c ~ Gamma(alpha = 0.001, beta = 1000)
tree prior         : Calibrated Yule, birthRateY ~ Gamma(alpha = 0.001, beta = 1000)
calibrations       : "c-h" (chimp–human) ~ LogNormal(M = 6.5, meanInRealSpace = true)
                     "o-h" (orangutan–human) ~ LogNormal(M = 15.8, meanInRealSpace = true)
MCMC               : chainLength = 10000000, tracelog and treelog every 1000, screenlog every 10000
```

Raw data: `CEL.fa`, `CLPS.fa` — the merged CEL and CLPS sequences of the HPRC samples (including the  
DUP1 / DUP2 / DUP3 copies) and of the Great Ape references, produced by `pickCEL.sh` and  
`pickCLPS.sh` with `samtools faidx`; the MAFFT alignments and NEXUS files are regenerated by the  
commands above and are not shipped.

Final results: `CEL.mcmc.trees.pdf`, `CLPS.mcmc.trees.pdf`

**Software:** SAMtools 1.6, MAFFT 7.310, ALTER 1.3.4, BEAUti / BEAST 2.6.7, TreeAnnotator,  
FigTree 1.4.4. **External input:** HPRC year-1 assemblies and the Great Ape assemblies  
(`Susie.fasta`, `Yerkes_chimp_pedigree.fasta`) on the cluster.
